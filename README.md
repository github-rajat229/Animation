# CSS Animation Examples

A responsive web project demonstrating various CSS keyframe animations, UI visualizers, and loader effects using pure HTML and CSS.

---

## 🚀 Features

### 🎨 Basic Animations (Top Row)
* **Color (`.box1`):** Cycles through multiple background colors over a 5-second loop.
* **Move (`.box2`):** Translates elements up and down along the vertical Y-axis.
* **Rotate (`.box3`):** Continuous rotation in 90° steps completing a full 360° spin.
* **Pulse (`.box4`):** Smooth scaling between `100%` and `150%` size.
* **Fade (`.box5`):** Opacity modulation between fully visible (`1`) and semi-transparent (`0.5`).
* **Load (`.box6`):** Continuous spinning circular loader using borders.

### 🔄 Complex Animations (Bottom Row)
* **Square Path Animation:** Animates an element along the inner perimeter of a dashed square container.
* **Google Loader Animation:** A wave effect created using staggered `animation-delay` intervals on colored dots.

---

## 🛠️ Built With

* **HTML5:** Page structure and semantic elements.
* **CSS3:** `@keyframes`, Flexbox positioning, CSS transforms, and viewport units (`vh`, `vw`).
